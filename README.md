# CONSTRUCTORA ND, S.A. — Landing page

React + Vite + Tailwind.

```
npm install
npm run dev      # http://localhost:3000
npm run build
```

Formulário: defina `VITE_FORM_ENDPOINT` em `.env.local` para enviar as consultas de verdade. Sem isso o envio é simulado e a página avisa "Versión de demostración".
